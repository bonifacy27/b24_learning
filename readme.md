# Заявки на обучение

Набор страниц Bitrix24 для создания и просмотра заявок на обучение.

## Файлы

- `create_request.php` — форма создания заявки для текущего пользователя. Поля формы меняются в зависимости от выбранного типа обучения.
- `list.php` — список доступных пользователю заявок, фильтрация, сортировка и выгрузка в Excel.

## Настройка

Скрипты рассчитаны на инфоблок заявок `382` рабочей группы `225`. Идентификаторы свойств и шаблона бизнес-процесса заданы константами и картой свойств в начале PHP-файлов. Перед переносом в другую среду проверьте эти значения.

Свойство `TIP_OBUCHENIYA` (`PROPERTY_3010`) должно иметь тип «Список». Для формы создания используются значения списка с ID `6407` («Внутреннее обучение») и `6408` («Внешнее обучение»).

## Возможности списка

- поиск по сотруднику, городу и теме;
- фильтр по типу обучения;
- сортировка по основным столбцам;
- экспорт отфильтрованных заявок в `.xls` с данными сотрудника, его подразделения и руководителя.

Выгрузка учитывает права текущего пользователя (`CHECK_PERMISSIONS`) и активные фильтры. Непосредственный руководитель определяется штатным методом Bitrix `CIntranetUtils::GetDepartmentManager()` по подразделениям сотрудника из `UF_DEPARTMENT`. Если метод не вернул руководителя, используется резервный поиск по `UF_HEAD` вверх по иерархии подразделений.

## Проверка

Минимальная локальная проверка синтаксиса:

```bash
php -l list.php
php -l create_request.php
```

Полноценная функциональная проверка выполняется в установленном Bitrix24 с модулями `iblock`, `lists`, `bizproc` и `intranet`.
